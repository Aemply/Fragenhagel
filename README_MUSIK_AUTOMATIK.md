# Fragenhagel v59 – Musik: Falsch => Play

Änderung gegenüber v58:
- Bei einer Musikrunde startet nach dem Klick auf „Falsch“ automatisch wieder die Wiedergabe.
- Die bestehende Spotify-Premium-Wiedergabe, Player-Oberfläche, Buzzer-Automatik und Synchronisationslogik bleiben erhalten.
- Der automatische Play-Aufruf erfolgt mit kurzer Verzögerung, damit der serverseitige „wrong“-State zuerst verarbeitet werden kann.
